The camera keeps the person.

You already point a camera at the cashier and the counter. That shows who was there. It does not show which button they pressed, what total they rang, or where a mistake started.

This keeps the screen.

Install it on the point-of-sale tablet, or run it on the Windows PC. When the screen changes, a clip starts. When the screen sits still, it stops. The tablet and the PC show up on the same watch page.

How a shift gets recorded

  1. 01

    Put it on the register

    On Android, install the APK on the tablet. On Windows, unzip the download and run TillRecorder.exe. The Windows app stays in the tray.

  2. 02

    Pair it once

    On the watch page, press Pair a register and type that code into the tablet or the Windows app. You do not type a web address or a token on the till. Android captures the screen itself, so there is no system screen-share prompt. Turn on Till Recorder in Accessibility one time. It stays on after that, including after a restart, and a notice stays visible. Windows pairs with the code and records from the tray. If watching was already on, the till starts again after its own restart.

  3. 03

    Watch from here

    The watch page opens as a wall of tills. Open one to see the live screen, the front camera, and what was typed, all at the same moment. Set the cashier’s name for that stretch. Search a word or an amount, such as 10000, and the recording jumps to the second it was typed. Download one clip before you delete it, or delete a clip or a whole day. The page stays signed in, and the live view comes back after the monitoring computer loses internet or restarts. Android live screen is about 3 frames a second. The Windows desktop is smooth.

An account, then a plan

Sign in with Google. A new account stays pending until management approves it. After that, request a plan from your account page. Management approves the plan and collects the payment. This site does not take a card.

You only see your own tills: live view, playback, search, camera, and stop or start recording. Pair a register only after the account is approved and a plan is active. If the plan expires, recording pauses and the video stays hidden until a new plan is approved. The till stays paired.

Downloads

Unruly POS is one app for the till, on Android tablets and on Windows PCs. Install it, open it, and pair it with a code from the watch page. You do not type a web address or a token on the till. The first time you open it you also set a master PIN: that PIN unlocks the app, protects its settings and Prevent uninstall, and is the Admin PIN used to create cashier PINs in the POS. The recorder is built in, so there is no separate recorder app or tray icon to install. It records the till screen and the register camera (front or back on Android, the webcam on Windows) while it is watching. Stop recording on a register pauses uploads, and Start recording turns them back on without a new pair code. Clips already saved stay. The Till Recorder downloads below are the recorder on its own, for stores that do not use the Unruly POS app. Recordings upload to your Cloudflare account. This website is where you watch them.
