The camera keeps the person.

You already point a camera at the cashier and the counter. That shows who was there. It does not show which button they pressed, what total they rang, or where a mistake started.

This keeps the screen.

Install it on the point-of-sale tablet, or run it on the Windows PC. When the screen changes, a clip starts. When the screen sits still, it stops. The tablet and the PC show up on the same watch page.

How a shift gets recorded

  1. 01

    Put it on the register

    On Android, install the APK on the tablet. On Windows, unzip the download and run TillRecorder.exe. The Windows app stays in the tray.

  2. 02

    Pair it once

    On the watch page, press Pair a register and type that code into the tablet or the Windows app. You do not type a long token. Android captures the screen itself, so there is no system screen-share prompt. Turn on Till Recorder in Accessibility one time. It stays on after that, including after a restart, and a notice stays visible. Windows pairs with the code and records from the tray.

  3. 03

    Watch from here

    Both registers appear on the same watch page. Turn the front camera or the webcam on and off from that page. Android live screen is about 3 frames a second, because the phone screenshot is that slow. The Windows desktop is smooth, about 15 to 30 frames a second or faster. The camera is real video. Delete one clip, or delete the whole day.

Two downloads

The Android APK is for the tablet. The Windows zip is for the point-of-sale PC: unzip it and run TillRecorder.exe. Pair either one with a code from the watch page. The Windows app records the desktop and the webcam and stays in the tray. Recordings upload to your Cloudflare account. This website is where you watch them.
